Integrál — Zsoldos-lista I.: határozatlan integrál

Primitív függvény, integráltáblázat, átalakítások, lineáris belső függvény, az \(\frac{f'}{f}\) és az \(f^n\cdot f'\) minta, helyettesítés. A végeredmény minden feladatnál lenyitható — előbb számolj, és ellenőrizz deriválással!

AlapKözépNehézJoker

🟢 Alapszint — Zöldfülű

1. Határozd meg a primitív függvényeket (olyan \(F\)-et keresünk, amelynek a deriváltja az adott függvény), és ellenőrizd deriválással!

  1. \(\displaystyle\int 4 x\,dx\)
  2. \(\displaystyle\int x^{4}\,dx\)
  3. \(\displaystyle\int - 4 t^{3}\,dt\)
  4. \(\displaystyle\int - 5 \sin x\,dx\)
  5. \(\displaystyle\int 2 e^{x}\,dx\)
Végeredmény
  1. \(2 x^{2}+C\)
  2. \(\dfrac{x^{5}}{5}+C\)
  3. \(- t^{4}+C\)
  4. \(5 \cos x+C\)
  5. \(2 e^{x}+C\)

2. Döntsd el deriválással, hogy az \(F\) primitív függvénye-e az \(f\) függvénynek! Ha nem, javítsd ki \(F\)-et!

  1. \(f(x)=3x^2-4x+1\), \(F(x)=x^3-2x^2+x-5\)
  2. \(f(x)=\dfrac{1}{x^2}\), \(F(x)=7-\dfrac1x\)
  3. \(f(x)=(3x+2)^3\), \(F(x)=\dfrac{(3x+2)^4}{4}\)
Végeredmény
  1. igen: \(F'(x)=3x^2-4x+1=f(x)\)
  2. igen: \(F'(x)=\dfrac{1}{x^2}=f(x)\)
  3. nem: \(F'(x)=\dfrac{4(3x+2)^3\cdot 3}{4}=3(3x+2)^3\ne f(x)\) — a belső függvény deriváltja miatt még \(3\)‑mal osztani kell; helyesen például \(F(x)=\dfrac{(3x+2)^4}{12}\)

3. Határozd meg az \(f\) függvény azon \(F\) primitív függvényét, amelynek grafikonja átmegy az \(M\) ponton!

  1. \(f(x)=3x^2-6x\), \(M(2;\,1)\)
  2. \(f(x)=2x-4x^3\), \(M(1;\,3)\)
  3. \(f(x)=2x-\dfrac{2}{x^3}\), \(M(1;\,2)\)
Végeredmény
  1. \(F(x)=x^3-3x^2+C\), \(F(2)=-4+C=1\), így \(C=5\): \(F(x)=x^3-3x^2+5\)
  2. \(F(x)=x^2-x^4+C\), \(F(1)=C=3\): \(F(x)=x^2-x^4+3\)
  3. \(F(x)=x^2+\dfrac{1}{x^2}+C\), \(F(1)=2+C=2\), így \(C=0\): \(F(x)=x^2+\dfrac{1}{x^2}\)

4. Írd át a törteket és a gyököket hatvánnyá, majd integrálj!

  1. \(\displaystyle\int \dfrac{1}{x^{3}}\,dx\)
  2. \(\displaystyle\int \dfrac{4}{x^{5}}\,dx\)
  3. \(\displaystyle\int x \sqrt{x}\,dx\)
  4. \(\displaystyle\int \sqrt[3]{x^{2}}\,dx\)
  5. \(\displaystyle\int \dfrac{3}{\sqrt[4]{x}}\,dx\)
Végeredmény
  1. \(- \dfrac{1}{2 x^{2}}+C\)
  2. \(- \dfrac{1}{x^{4}}+C\)
  3. \(\dfrac{2 x^{2} \sqrt{x}}{5}+C\)
  4. \(\dfrac{3 x \sqrt[3]{x^{2}}}{5}+C\)
  5. \(4 \sqrt[4]{x^{3}}+C\)

5. Integráld tagonként a polinomokat!

  1. \(\displaystyle\int \left(5 x^{3} - 4 x^{2} - 3 x + 5\right)\,dx\)
  2. \(\displaystyle\int \left(x^{3} - 2 x^{2} + 2 x - 1\right)\,dx\)
  3. \(\displaystyle\int \left(2 x^{2} - 3 x + 4\right)\,dx\)
  4. \(\displaystyle\int \left(9 x^{8} - 6 x^{5} + x - 7\right)\,dx\)
Végeredmény
  1. \(\dfrac{5 x^{4}}{4} - \dfrac{4 x^{3}}{3} - \dfrac{3 x^{2}}{2} + 5 x+C\)
  2. \(\dfrac{x^{4}}{4} - \dfrac{2 x^{3}}{3} + x^{2} - x+C\)
  3. \(\dfrac{2 x^{3}}{3} - \dfrac{3 x^{2}}{2} + 4 x+C\)
  4. \(x^{9} - x^{6} + \dfrac{x^{2}}{2} - 7 x+C\)

6. Számítsd ki az integrálokat a táblázat segítségével!

  1. \(\displaystyle\int \left(3 e^{x} - 2 \sin x\right)\,dx\)
  2. \(\displaystyle\int \left(4 \cos x + \dfrac{1}{\cos^{2} x }\right)\,dx\)
  3. \(\displaystyle\int \left(2^{x} + \dfrac{1}{\sin^{2} x }\right)\,dx\)
  4. \(\displaystyle\int \left(5 e^{x} - \dfrac{3}{x}\right)\,dx\)
Végeredmény
  1. \(3 e^{x} + 2 \cos x+C\)
  2. \(4 \sin x + \operatorname{tg} x+C\)
  3. \(\dfrac{2^{x}}{\ln 2}-\operatorname{ctg} x+C\)
  4. \(5 e^{x} - 3 \ln \left|x\right|+C\)

7. Írd át a gyököket törtkitevős hatvánnyá, és integrálj!

  1. \(\displaystyle\int \left(x^{4} - \sqrt{x} + x \sqrt[3]{x} + \dfrac{1}{x^{2}}\right)\,dx\)
  2. \(\displaystyle\int \left(4 \sqrt{x^{3}} + \dfrac{2}{\sqrt{x}}\right)\,dx\)
  3. \(\displaystyle\int \left(\sqrt[3]{x} - \dfrac{1}{\sqrt[3]{x^{2}}}\right)\,dx\)
Végeredmény
  1. \(\dfrac{x^{5}}{5} - \dfrac{2 x \sqrt{x}}{3} + \dfrac{3 x^{2} \sqrt[3]{x}}{7} - \dfrac{1}{x}+C\)
  2. \(\dfrac{8 x^{2} \sqrt{x}}{5} + 4 \sqrt{x}+C\)
  3. \(\dfrac{3 x \sqrt[3]{x}}{4} - 3 \sqrt[3]{x}+C\)

8. Bontsd fel a törtet tagokra, és integrálj!

  1. \(\displaystyle\int \dfrac{x - 2}{x^{3}}\,dx\)
  2. \(\displaystyle\int \dfrac{10 x^{8} + 3}{x^{4}}\,dx\)
  3. \(\displaystyle\int \dfrac{3 x^{3} + 1}{5 x}\,dx\)
  4. \(\displaystyle\int \dfrac{6 + 2 x + x^{2}}{x^{4}}\,dx\)
Végeredmény
  1. \(- \dfrac{1}{x} + \dfrac{1}{x^{2}}+C\)
  2. \(2 x^{5} - \dfrac{1}{x^{3}}+C\)
  3. \(\dfrac{x^{3}}{5}+\dfrac{1}{5}\ln\left|x\right|+C\)
  4. \(- \dfrac{2}{x^{3}} - \dfrac{1}{x^{2}} - \dfrac{1}{x}+C\)

9. Lineáris belső függvény: integrálj, és ellenőrizd deriválással!

  1. \(\displaystyle\int \left(3 x + 1\right)^{4}\,dx\)
  2. \(\displaystyle\int \left(5 - 2 x\right)^{9}\,dx\)
  3. \(\displaystyle\int \left(\dfrac{x}{2} + 1\right)^{3}\,dx\)
  4. \(\displaystyle\int \sqrt[3]{4 x + 3}\,dx\)
Végeredmény
  1. \(\dfrac{\left(3 x + 1\right)^{5}}{15}+C\)
  2. \(-\dfrac{\left(5 - 2 x\right)^{10}}{20}+C\)
  3. \(\dfrac{\left(\dfrac{x}{2} + 1\right)^{4}}{2}+C\)
  4. \(\dfrac{3 \left(4 x + 3\right) \sqrt[3]{4 x + 3}}{16}+C\)

10. Lineáris belső függvény — gyök és tört:

  1. \(\displaystyle\int \sqrt{3 x + 1}\,dx\)
  2. \(\displaystyle\int \dfrac{1}{\sqrt{4 x - 1}}\,dx\)
  3. \(\displaystyle\int \dfrac{1}{5 x + 2}\,dx\)
  4. \(\displaystyle\int \dfrac{3}{2 - x}\,dx\)
  5. \(\displaystyle\int \dfrac{1}{\left(2 x + 1\right)^{2}}\,dx\)
Végeredmény
  1. \(\dfrac{2 \left(3 x + 1\right) \sqrt{3 x + 1}}{9}+C\)
  2. \(\dfrac{\sqrt{4 x - 1}}{2}+C\)
  3. \(\dfrac{1}{5}\ln\left|5x+2\right|+C\)
  4. \(-3\ln\left|2-x\right|+C\)
  5. \(- \dfrac{1}{2 \left(2 x + 1\right)}+C\)

11. Lineáris belső függvény — exponenciális és trigonometrikus:

  1. \(\displaystyle\int e^{5 x}\,dx\)
  2. \(\displaystyle\int e^{1 - x}\,dx\)
  3. \(\displaystyle\int \sin\left(3 x + 2\right)\,dx\)
  4. \(\displaystyle\int \cos\left(\dfrac{x}{2}\right)\,dx\)
  5. \(\displaystyle\int \dfrac{1}{\cos^{2} 3x }\,dx\)
Végeredmény
  1. \(\dfrac{e^{5 x}}{5}+C\)
  2. \(- e^{1 - x}+C\)
  3. \(-\dfrac{\cos\left(3 x + 2\right)}{3}+C\)
  4. \(2 \sin\left(\dfrac{x}{2}\right)+C\)
  5. \(\dfrac{\operatorname{tg} 3x }{3}+C\)

12. Véd Vilmos házi feladatában ez áll: \(\displaystyle\int(4x-1)^5\,dx=\dfrac{(4x-1)^6}{6}+C\). Ellenőrizd deriválással, és mondd meg, mit rontott el! Utána számítsd ki a másik két integrált is — deriválással ellenőrizve.

  1. Mi a hiba Véd Vilmos eredményében?
  2. \(\displaystyle\int e^{-4x}\,dx\)
  3. \(\displaystyle\int\dfrac{2}{3x-1}\,dx\)
Végeredmény
  1. hibás: \(\left(\dfrac{(4x-1)^6}{6}\right)'=4(4x-1)^5\) — elfelejtett a belső függvény deriváltjával (\(4\)‑gyel) osztani; helyesen \(\dfrac{(4x-1)^6}{24}+C\)
  2. \(-\dfrac{e^{-4x}}{4}+C\)
  3. \(\dfrac{2}{3}\ln\left|3x-1\right|+C\)

🟡 Középszint — X-Force

1. Határozd meg az \(f\) függvénynek azt az \(F\) primitív függvényét, amelynek grafikonja átmegy az \(M\) ponton!

  1. \(f(x)=e^x+2x\), \(M(0;\,-1)\)
  2. \(f(x)=\sin x+\cos x\), \(M\left(\dfrac{\pi}{2};\,2\right)\)
  3. \(f(x)=\dfrac{1}{\cos^2x}-\dfrac{1}{\sin^2x}\), \(M\left(\dfrac{\pi}{4};\,2\right)\)
  4. \(f(x)=\dfrac{3}{x^2}-\dfrac{2}{x^3}\), \(M(1;\,4)\)
Végeredmény
  1. \(F(x)=e^x+x^2+C\), \(F(0)=1+C=-1\): \(F(x)=e^x+x^2-2\)
  2. \(F(x)=-\cos x+\sin x+C\), \(F\left(\dfrac{\pi}{2}\right)=1+C=2\): \(F(x)=\sin x-\cos x+1\)
  3. \(F(x)=\operatorname{tg}x+\operatorname{ctg}x+C\), \(F\left(\dfrac{\pi}{4}\right)=2+C=2\): \(F(x)=\operatorname{tg}x+\operatorname{ctg}x\)
  4. \(F(x)=-\dfrac{3}{x}+\dfrac{1}{x^2}+C\), \(F(1)=-2+C=4\): \(F(x)=-\dfrac{3}{x}+\dfrac{1}{x^2}+6\)

2. Határozd meg az \(f\) függvényt, ha ismert a második deriváltja és a grafikonjának két pontja! (Kétszer integrálj: két állandó lesz, a két pont két egyenletet ad.)

  1. \(f''(x)=e^x\), \(M(0;\,-1)\), \(N(2;\,e^2)\)
  2. \(f''(x)=6x-4\), \(M(1;\,0)\), \(N(2;\,2)\)
Végeredmény
  1. \(f'(x)=e^x+C_1\), \(f(x)=e^x+C_1x+C_2\); \(1+C_2=-1\), \(e^2+2C_1+C_2=e^2\), így \(C_2=-2\), \(C_1=1\): \(f(x)=e^x+x-2\)
  2. \(f(x)=x^3-2x^2+C_1x+C_2\); \(C_1+C_2=1\), \(2C_1+C_2=2\), így \(C_1=1\), \(C_2=0\): \(f(x)=x^3-2x^2+x\)

3. Szorozz be vagy alakítsd át, és csak utána integrálj!

  1. \(\displaystyle\int \dfrac{\left(x + 1\right) \left(x^{2} - 3\right)}{3 x^{2}}\,dx\)
  2. \(\displaystyle\int \left(\sqrt{x} + 1\right) \left(x - \sqrt{x} + 1\right)\,dx\)
  3. \(\displaystyle\int \left(x^{2} + 1\right)^{2}\,dx\)
  4. \(\displaystyle\int \dfrac{\left(1 - \sqrt{x}\right)^{2}}{x}\,dx\)
Végeredmény
  1. \(\dfrac{x^{2}}{6}+\dfrac{x}{3}-\ln\left|x\right|+\dfrac{1}{x}+C\)
  2. \(\dfrac{2 x^{2} \sqrt{x}}{5} + x+C\)
  3. \(\dfrac{x^{5}}{5} + \dfrac{2 x^{3}}{3} + x+C\)
  4. \(\ln\left|x\right|-4\sqrt{x}+x+C\)

4. Bontsd fel a gyökös törtet tagokra, és integrálj!

  1. \(\displaystyle\int \dfrac{\left(x - \sqrt{x}\right) \left(1 + \sqrt{x}\right)}{\sqrt{x}}\,dx\)
  2. \(\displaystyle\int \dfrac{x^{4} + \sqrt{x^{3}} + \sqrt{x} + 3}{x \sqrt{x}}\,dx\)
  3. \(\displaystyle\int \dfrac{x^{2} + \sqrt{x^{3}} + 3}{\sqrt{x}}\,dx\)
Végeredmény
  1. \(\dfrac{x^{2}}{2} - x+C\)
  2. \(\dfrac{2}{7}x^{3}\sqrt{x}+x+\ln\left|x\right|-\dfrac{6}{\sqrt{x}}+C\)
  3. \(\dfrac{2 x^{2} \sqrt{x}}{5} + \dfrac{x^{2}}{2} + 6 \sqrt{x}+C\)

5. Alakítsd át azonossággal (vagy a hatványozás azonosságaival), és integrálj!

  1. \(\displaystyle\int \dfrac{e^{x} + 1}{e^{x}}\,dx\)
  2. \(\displaystyle\int \operatorname{tg}^{2} x\,dx\)
  3. \(\displaystyle\int \dfrac{2 \cos^{2} x + 1}{\cos^{2} x }\,dx\)
  4. \(\displaystyle\int \dfrac{\cos 2x }{\sin^{2} x \cos^{2} x }\,dx\)
  5. \(\displaystyle\int \dfrac{1 - \sin^{3} x }{\sin^{2} x }\,dx\)
Végeredmény
  1. \(x - e^{- x}+C\)
  2. \(\operatorname{tg} x - x+C\)
  3. \(2 x + \operatorname{tg} x+C\)
  4. \(- \operatorname{ctg} x - \operatorname{tg} x+C\)
  5. \(- \operatorname{ctg} x + \cos x+C\)

6. Az \(\displaystyle\int\dfrac{f'(x)}{f(x)}\,dx=\ln\left|f(x)\right|+C\) minta — ha kell, igazítsd a szorzót!

  1. \(\displaystyle\int \dfrac{2 x + 1}{x^{2} + x - 3}\,dx\)
  2. \(\displaystyle\int \dfrac{x^{2}}{x^{3} + 1}\,dx\)
  3. \(\displaystyle\int \dfrac{e^{x}}{e^{x} + 1}\,dx\)
  4. \(\displaystyle\int \operatorname{ctg} x\,dx\)
  5. \(\displaystyle\int \dfrac{\cos x }{1 + 2 \sin x }\,dx\)
  6. \(\displaystyle\int \dfrac{1}{x \ln x }\,dx\)
Végeredmény
  1. \(\ln\left|x^{2}+x-3\right|+C\)
  2. \(\dfrac{1}{3}\ln\left|x^{3}+1\right|+C\)
  3. \(\ln\left(e^{x}+1\right)+C\)
  4. \(\ln\left|\sin x\right|+C\)
  5. \(\dfrac{1}{2}\ln\left|1+2\sin x\right|+C\)
  6. \(\ln\left|\ln x\right|+C\)

7. Az \(\displaystyle\int\bigl[f(x)\bigr]^n\cdot f'(x)\,dx=\dfrac{\bigl[f(x)\bigr]^{n+1}}{n+1}+C\) (\(n\ne-1\)) minta:

  1. \(\displaystyle\int x \left(x^{2} - 1\right)^{4}\,dx\)
  2. \(\displaystyle\int \dfrac{x}{\left(x^{2} + 1\right)^{2}}\,dx\)
  3. \(\displaystyle\int \sin^{2} x \cos x\,dx\)
  4. \(\displaystyle\int \dfrac{\sin x }{\cos^{3} x }\,dx\)
  5. \(\displaystyle\int \dfrac{x^{2}}{\sqrt{1 + x^{3}}}\,dx\)
Végeredmény

  2. \(- \dfrac{1}{2 \left(x^{2} + 1\right)}+C\)
  3. \(\dfrac{\sin^{3} x }{3}+C\)
  4. \(\dfrac{1}{2 \cos^{2} x }+C\)
  5. \(\dfrac{2 \sqrt{1 + x^{3}}}{3}+C\)

8. Exponenciális függvény nemlineáris belső függvénnyel — keresd meg a belső függvény deriváltját!

  1. \(\displaystyle\int x^{2} e^{x^{3}}\,dx\)
  2. \(\displaystyle\int e^{\sin x } \cos x\,dx\)
  3. \(\displaystyle\int \dfrac{e^{\frac{1}{x}}}{x^{2}}\,dx\)
  4. \(\displaystyle\int 3^{x^{2}} x\,dx\)

  2. \(e^{\sin x }+C\)

9. Trigonometrikus függvény nemlineáris belső függvénnyel:

  2. \(\displaystyle\int \dfrac{\sin \sqrt{x} }{\sqrt{x}}\,dx\)
  3. \(\displaystyle\int \dfrac{x^{2}}{\cos^{2}\left(x^{3}\right)}\,dx\)
  4. \(\displaystyle\int \sin x \cos\left(\cos x\right)\,dx\)
Végeredmény

🔴 Nehéz szint — Maximális erőbedobás

1. Keresd meg a jó helyettesítést (\(t=g(x)\)), írd át az integrált \(t\)-re (ha kell, \(x\)-et is fejezd ki \(t\)-vel), integrálj, és helyettesíts vissza!

  1. \(\displaystyle\int x^{3} \sqrt{x^{4} + 1}\,dx\)
  2. \(\displaystyle\int x \sqrt{x - 1}\,dx\)
  3. \(\displaystyle\int \dfrac{\sin 2x }{1 + \sin^{2} x }\,dx\)
  4. \(\displaystyle\int \dfrac{x}{\sqrt{x + 1}}\,dx\)
Végeredmény
  1. \(\dfrac{\left(x^{4} + 1\right) \sqrt{x^{4} + 1}}{6}+C\) (\(t=x^4+1\), \(dt=4x^3\,dx\))
  2. \(\dfrac{2 \left(x - 1\right)^{2} \sqrt{x - 1}}{5} + \dfrac{2 \left(x - 1\right) \sqrt{x - 1}}{3}+C\) (\(t=x-1\), \(x=t+1\), \(dx=dt\): \(\displaystyle\int(t+1)\sqrt t\,dt\))
  3. \(\ln\left(1+\sin^{2}x\right)+C\) (\(t=1+\sin^2x\), \(dt=2\sin x\cos x\,dx=\sin2x\,dx\))
  4. \(\dfrac{2 \left(x + 1\right) \sqrt{x + 1}}{3} - 2 \sqrt{x + 1}+C\) (\(t=x+1\), \(x=t-1\), \(dx=dt\): \(\displaystyle\int\dfrac{t-1}{\sqrt t}\,dt\))

2. Alakítsd át trigonometrikus azonossággal, és utána helyettesíts!

  1. \(\displaystyle\int \sin^{3} x\,dx\)
  2. \(\displaystyle\int \cos^{5} x\,dx\)
  3. \(\displaystyle\int \dfrac{\sin 2x }{\cos^{3} x }\,dx\)
  4. \(\displaystyle\int \operatorname{tg}^{3} x\,dx\)
Végeredmény
  1. \(- \cos x + \dfrac{\cos^{3} x }{3}+C\)
  2. \(\sin x - \dfrac{2 \sin^{3} x }{3} + \dfrac{\sin^{5} x }{5}+C\)
  3. \(\dfrac{2}{\cos x }+C\)
  4. \(\dfrac{\operatorname{tg}^{2}x}{2}+\ln\left|\cos x\right|+C\)

🃏 Joker

★ Az \(e^{-x^2}\) függvény primitív függvénye nem írható fel elemi függvényekkel — az \(\displaystyle\int x\,e^{-x^2}\,dx\) viszont könnyen kiszámolható. Számítsd ki, és magyarázd meg a különbséget!

Végeredmény

\(\displaystyle\int x\,e^{-x^2}\,dx=-\dfrac{1}{2}e^{-x^2}+C\) (\(t=-x^2\), \(dt=-2x\,dx\)). Itt az \(x\) szorzó (egy \(-2\)-es szorzótól eltekintve) éppen a belső függvény deriváltja, ezért működik a helyettesítés. Az \(\int e^{-x^2}dx\)-ből ez a szorzó hiányzik; a primitív függvény létezik, de nem írható fel véges sok elemi függvénnyel (lásd a Gauss-görbét).
